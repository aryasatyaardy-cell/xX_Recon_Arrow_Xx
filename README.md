# xX_Recon_Arrow_Xx
This arrow is designed to be launched and collect sound data from the surrounding area, designed to wait in an area for potential victim of natural disaster

## Hardware
- Xiao ESP32 by Seeed Studio
- INMP441
- BMI Gyroscope sensor
My first plan is to use gps module but due to budget, I'm unable to afford it

- Small LiPo battery

This arrow is inspired by Sova's recon bolt from Valorant
